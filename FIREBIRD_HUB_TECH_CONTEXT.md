# Firebird Hub — full technical context (for continuing in a new chat)

Everything wired together for the Fremont HS ASB app so a new conversation can pick up without re-discovering it.

## 1. Deploy / hosting (Vercel)
- **App:** repo `github.com/fremontasbtech-sudo/App`. Vercel project **firebirdhub** (team `fremont-asb-tech`), **Root Directory = `FirebirdHub/`**. Push to `main` → auto-deploy to **https://firebirdhub.vercel.app** (~1–2 min). Serverless functions live under `FirebirdHub/api/`.
- **Website (separate):** repo `fremontasbtech-sudo/fremontasb-site` → **https://fremontasb-site.vercel.app**.
- `FirebirdHub/vercel.json` sets `Cache-Control: max-age=0, must-revalidate` so assets always revalidate; also bump `?v=NN` on the `<script>/<link>` tags in `index.html` each deploy.
- **Push auth:** needs a **fremontasbtech-sudo** token (classic `repo` scope, or fine-grained **Contents: Read+write**). The Mac keychain resolves git to `fhsastrophysics` (no write) → plain push 403s. Push with `git -c credential.helper= push https://fremontasbtech-sudo:<TOKEN>@github.com/fremontasbtech-sudo/App.git main`.

## 2. App file structure (`App/`)
- `FirebirdHub/` — **canonical hostable folder**: `index.html`, `app.js` (all UI logic), `styles.css`, `qr.js`, `vision.js` (spirit fit-check), `teacher.html` (Fire Bucks staff console), `manifest.webmanifest`, `assets/`, and `api/ask.js` (the Felipe chatbot function).
- `Firebird Hub - Fremont ASB.html` — single-file mirror (CSS + qr.js + vision.js + app.js inlined). **Keep in sync** with `FirebirdHub/` on every change.
- `backend/` — Apps Script source copies: `Code.gs` (Fire Bucks), `FeaturedEvents.gs`, `SportsSync.gs`, `README.md`.
- `athletics-data/` — scrape context (`SOURCES.md`, `full-season.csv`).
- `FIREBIRD_HUB_APP_CONTEXT.md` — handoff for the website chat.

## 6. Felipe chatbot (`FirebirdHub/api/ask.js`)
- Vercel serverless function. Model **`gemini-3.6-flash`** (endpoint `generativelanguage.googleapis.com/v1beta/models/<MODEL>:generateContent`). **`gemini-2.0-flash` was retired** — do not use it.
- Reads **live** Events + Sports from the Sheet each call (cached ~5 min) and injects them as context, so it self-updates. Scoped to school topics, refuses off-topic/jailbreaks, routes self-harm to 988 + a trusted adult.
- **Key: `GEMINI_API_KEY`** — server-side only, set in the **firebirdhub Vercel project env (Production)**. Never in client code.
